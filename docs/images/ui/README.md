# Synthetic TMAR UI captures

Eleven actual UI screenshots and twelve thumbnails, captured November 3, 2026
(Europe/Rome), with source `08150a0ba2eecb914a91095192ec29e31c55ea64`. The extra thumbnail is a downscale of the
separately authorized Tubo Finale hero; its full-size original remains outside
this folder. The hero bytes were not changed.

`manifest.json` records each full synthetic screenshot's SHA-256, source revision,
caption, byte count and capture platform. Full captures are 1720 x 1080; thumbnails
are proportionally reduced to 480 pixels wide. No cropping, retouching, invented
controls or generated UI imagery. No private model files, user projects or
credentials are present. The agent connection remained off.

UI branding and licenses are retained. Synthetic fixtures were generated by the
repository script under the repository's license. The captures document available
controls and remain subject to user review, not final product/geometry acceptance.
